👥 Clientes (DeskInstaller)

GET
/api/clientes
Lista todos os clientes cadastrados
Exemplo: 
curl http://localhost:8080/api/clientes
GET
/api/clientes/{id}
Busca cliente específico por ID
Exemplo: 
curl http://localhost:8080/api/clientes/1
GET
/api/clientes/buscar/nome?q={nome}
Busca clientes por nome (busca parcial, case insensitive)
Exemplo: 
curl "http://localhost:8080/api/clientes/buscar/nome?q=Silva"
GET
/api/clientes/buscar/email?email={email}
Busca cliente por email exato
Exemplo: 
curl "http://localhost:8080/api/clientes/buscar/email?email=joao@example.com"
GET
/api/clientes/buscar/telefone?telefone={telefone}
Busca clientes por telefone (celular ou residencial)
Exemplo: 
curl "http://localhost:8080/api/clientes/buscar/telefone?telefone=11999999999"
GET
/api/clientes/buscar?nome={nome}&email={email}&telefone={telefone}
Busca com filtros múltiplos (todos os parâmetros são opcionais)
Exemplo: 
curl "http://localhost:8080/api/clientes/buscar?nome=Silva&telefone=11999999999"
GET
/api/clientes/count
Retorna o total de clientes cadastrados
Exemplo de resposta: 
{ "total": 150 }
POST
/api/clientes
Cria um novo cliente (JSON)
Exemplo: 
curl -X POST http://localhost:8080/api/clientes \
  -H "Content-Type: application/json" \
  -d '{
    "nome": "João Silva",
    "email": "joao@example.com",
    "foneCelular": "11999999999"
  }'
PUT
/api/clientes/{id}
Atualiza um cliente existente
Exemplo: 
curl -X PUT http://localhost:8080/api/clientes/1 \
  -H "Content-Type: application/json" \
  -d '{
    "nome": "João Silva Atualizado",
    "email": "joao.novo@example.com"
  }'
DELETE
/api/clientes/{id}
Remove um cliente
Exemplo: 
curl -X DELETE http://localhost:8080/api/clientes/1
